## 🚀 Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/<ankitprajapati95199>/conditions-in-c.git
cd conditions-in-c
```

### 2️⃣ Compile with GCC

```bash
# Example: program16.c
gcc -Wall -Wextra program16.c -o program16
```

> 💡 `-Wall -Wextra` turns on helpful warnings that catch common mistakes early.

### 3️⃣ Run the program

| Platform | Command |
|----------|---------|
| 🪟 Windows | `.\program16.exe` |
| 🐧 Linux / 🍎 macOS | `./program16` |

# conditions-in-c
C Programming  -
# Level 2 — Conditions (if / else)

A collection of basic C programs demonstrating conditional control structures (`if`, `if-else`, and `else if` ladders) and formatted standard I/O.

---

## Problem Index

| Question No. | File Name | Description |
| :---: | :--- | :--- |
| **11** | `program11.c` | Write a program to read a number and check whether it is even or odd. |
| **12** | `program12.c` | Write a program to read a number and check whether it is positive, negative or zero. |
| **13** | `program13.c` | Write a program to read three numbers and find the largest among them. |
| **14** | `program14.c` | Write a program to read three numbers and find the smallest among them. |
| **15** | `program15.c` | Write a program to read a year and check whether it is a leap year or not. |
| **16** | `program16.c` | Write a program to read a character and check whether it is a vowel or a consonant. |

| **18** | `program18.c` | Write a program to read the marks of a student and print the grade (A/B/C/D/Fail). |
| **19** | `program19.c` | Write a program to read a number and check whether it is divisible by both 3 and 5. |
